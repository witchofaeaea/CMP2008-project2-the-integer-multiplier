# project-2-integer-multiplier
Template repository for Project 2: Integer Multiplier

## Student handout

See `PROJECT.md`.

## Workflow (No external test framework)

This project uses **file-based grading** (no external test framework):

- **`test_cases/`**: input pairs (two 32-bit binary strings per file)
- **`expected_outputs/`**: correct 64-bit binary strings (one per test)
- **`run_grader.py`**: runs `multiplier_student.simulate_multiplier` and scores it
- **`student_outputs/`**: optional (generated by `run_student.py`)

### Student

1. Implement the TODO block in `multiplier_student.py` (no `+ - * / // %`).
2. Generate outputs:

```bash
python3 run_student.py
```

3. Grade:

```bash
python3 run_grader.py
```
